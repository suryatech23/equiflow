# EquiFlow | Full-Stack Personal Finance & Expense Splitting Platform

EquiFlow is a production-grade full-stack personal finance and group expense splitting platform designed to handle multi-currency balances, automated debt simplification algorithms, and real-time net-worth allocation visualization.

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js, REST APIs
- **Database:** PostgreSQL
